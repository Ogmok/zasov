# Засов — генератор паролей

Локальный генератор паролей и парольных фраз. Работает целиком в браузере на `crypto.getRandomValues`, ничего не отправляет на сервер.

**Сайт:** https://ogmok.github.io/zasov/

- длина от 8 до 64 символов, выбор групп: строчные, прописные, цифры, спецсимволы;
- в пароле гарантированно есть символ каждой выбранной группы;
- исключение похожих символов, оценка стойкости с объяснением;
- режим парольной фразы (словарь из 128 слов) и пакет из 5 вариантов;
- настройки сохраняются в `localStorage`, пароли — нет;
- встроенная самопроверка крайних значений.
